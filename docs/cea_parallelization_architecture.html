Post-processing
Dynamic scheduling: Unlike doSNOW's fixed round-robin (W1→S1,S5,S9… assigned at dispatch), mirai's dispatcher uses work-stealing — each daemon picks the next available task as soon as it finishes. Strategies that happen to run faster (fewer adenomas, shorter screening window) complete more tasks; no daemon sits idle while one slow strategy holds a slot.
Migration: what changes and why
🔁
Real reproducibility
set.seed() in the main process does not propagate to socket workers — each worker gets its own OS-seeded RNG. daemons(n, seed = 3) seeds one L'Ecuyer-CMRG stream per daemon, reproducible regardless of scheduling.
−set.seed(3)
makeCluster(n_cores) # seed not propagated
+daemons(n_cores, seed = 3) # actually reproducible
💾
dt_crc_pop sent once
everywhere() loads packages and dt_crc_pop into each daemon's global environment once at startup. Per-task payload drops from ~550 MB to <1 KB — the single largest RAM/network win.
−.packages = c("data.table","simcrc",...)
# dt_crc_pop auto-detected and copied per task
+everywhere({library(data.table);library(simcrc);...},
dt_crc_pop = dt_crc_pop) # once per daemon
🛑
Error surfacing
One bad strategy row currently causes the entire run to abort (or silently corrupt results) with a cryptic message. [.stop] terminates the map on the first worker error and surfaces the full stack trace immediately.
−foreach(...) %dopar% {...}
# one failure = cryptic abort or silent NULL
+mirai_map(l_strats, fn)[.stop, .progress]
# error surfaced with full stack trace
⚡
Dynamic scheduling
doSNOW assigns tasks round-robin at dispatch time — fixed. mirai's dispatcher uses work-stealing: each daemon takes the next task as soon as it finishes. Faster strategies don't leave slots idle while slow ones hold them.
−Round-robin: W1→S1,S5,S9… (fixed at launch)
+Work-stealing: daemon picks next free task
📊
Built-in progress + less boilerplate
The doSNOW progress bar requires a txtProgressBar + opts callback block. mirai provides it natively via [.progress]. The cluster setup/teardown collapses from ~12 lines to 2.
−pb <- txtProgressBar(min=0, max=n_ids, style=3, file=stderr())
opts <- list(progress=function(n) setTxtProgressBar(pb,n))
cl <- makeCluster(n_cores); registerDoSNOW(cl)
close(pb); stopCluster(cl)
+daemons(n_cores, seed=3)
mirai_map(l_strats, fn)[.stop, .progress]
daemons(0)
🔧
Section 7 single-strategy test — unchanged
Sections 7 (single FIT4585q1 test) and 8 (resource monitor — once the sys package is added) run after daemons(0) and require no changes. The resource monitor's recommended-cores formula remains valid.
!library(sys) missing → Section 8 crashes at sys::exec_background()

Proposed code skeleton — Section 3 replacement
# ── Install (once) ────────────────────────────────────────────────────────
# install.packages("mirai")

# ── Load ──────────────────────────────────────────────────────────────────
library(mirai)

n_cores <- ceiling(parallel::detectCores() / 2)
cat(sprintf("Running %d strategies across %d cores\n", n_ids, n_cores))

# ── Spawn daemons with reproducible RNG ───────────────────────────────────
daemons(n_cores, seed = 3)

# ── Pre-load packages + large shared objects ONCE per daemon ──────────────
everywhere({
  library(data.table)
  library(simcrc)
  library(ceacrc)
  library(dplyr)
},
  dt_crc_pop            = dt_crc_pop,           # shipped once per daemon
  cohort_age            = cohort_age,
  simcrc_model_version  = simcrc_model_version,
  log_file              = log_file
)

# ── Split df into a list of single-row data frames ────────────────────────
l_strategies <- split(df_screening_strategies, seq_len(n_ids))

# ── Parallel map ──────────────────────────────────────────────────────────
t_parallel_start <- proc.time()

mirai_map(
  l_strategies,
  function(run_id) {

    id               <- run_id$id
    strategy_name    <- run_id$strategy
    screening_years  <- seq(run_id$age_to_begin_screening,
                            run_id$age_to_end_screening,
                            run_id$frequency_screening)
    screening_modality <- run_id$modality
    follow_up          <- run_id$follow_up
    start_time         <- Sys.time()

    # ── body unchanged from current foreach block ─────────────────────
    capture.output({

      results_screening <- screening_detection(
        dt_crc_pop = dt_crc_pop,    # available from everywhere()
        # ... all parameters unchanged ...
      )
      dt_pop_scr <- results_screening$dt_pop_screening

      results_surveillance <- surveillance_detection(
        dt_pop_scr = dt_pop_scr,
        # ... all parameters unchanged ...
      )

      dt_export_final <- uspstf_summary(
        datatable          = results_surveillance,
        screening_modality = screening_modality,
        follow_up          = follow_up,
        screening_years    = screening_years,
        min_age            = cohort_age,
        max_age            = 100
      )
    })

    # ── file write + log (unchanged) ──────────────────────────────────
    execution_time <- difftime(Sys.time(), start_time, units = "mins")
    # ... header_string, writeLines, write.table, cat to log_file ...

    NULL
  }
)[.stop, .progress]   # surface first error + built-in progress bar

daemons(0)   # release all workers

t_parallel_total <- (proc.time() - t_parallel_start)[["elapsed"]]
log_msg(sprintf("All %d strategies completed in %.1f min on %d cores.",
                n_ids, t_parallel_total / 60, n_cores))

# resource monitor (add library(sys) at top to fix Section 8)
